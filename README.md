This project demonstrates the implementation of simple and multiple linear regression models using the Housing Price Prediction dataset. Using Python libraries such as Pandas, Scikit-learn, and Matplotlib, the data is first imported and preprocessed, including handling categorical variables. For simple linear regression, the relationship between house area and price is analyzed, while multiple linear regression includes additional features like bedrooms, bathrooms, and furnishing status. The dataset is split into training and testing sets, and models are trained using Scikit-learn’s LinearRegression. Evaluation metrics including Mean Absolute Error (MAE), Mean Squared Error (MSE), and R² Score are used to assess performance. The regression line is visualized in the simple model, and the influence of each feature is interpreted via the learned coefficients in the multiple regression model.
